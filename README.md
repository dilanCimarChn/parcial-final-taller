# Parcial final de taller

## Estado del repositorio

La revisión del árbol Git encontró únicamente este README. No hay código ejecutable, archivos de diseño ni una aplicación demostrable. No existe un comando de instalación o una demo que pueda documentarse de forma verificable.

Se conserva como registro de una práctica inicial. Antes de añadir desarrollo, el propietario debe definir su objetivo y, si corresponde, aportar una referencia de diseño o consigna real. El nombre del repositorio no acredita una tecnología utilizada ni una funcionalidad terminada.
